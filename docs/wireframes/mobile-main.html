Mobile — Écran principal (carrousel à 3 positions)

← Retour · mobile-main.html

Sur mobile (390×780), les trois zones du bas desktop deviennent un carrousel swipeable. Position par défaut : au milieu (sélection + actions). Le player chip compact à gauche du top bar reste cliquable pour ouvrir la fiche complète. Une pastille chat flotte au bas du map et affiche le dernier message — tap pour ouvrir le chat en bottom-sheet (cf. mobile-sheet.html).

À noter · Tour suivant = horaire informatif, pas de countdown. Chat accessible via la pastille overlay et l'onglet "Chat" dans la tab-bar (en remplacement de Forum, qui passe dans "Plus").

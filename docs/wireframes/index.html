Age of Olympia — Refonte UI/UX

/docs/wireframes/index.html

Proposition de refonte complète de l'interface d'Age of Olympia : barre haute avec player chip + caracs persistants, rail vertical gauche pour la navigation, map central avec le personnage au centre, chat persistant sur le bord droit, et zone basse en trois parties (minimap · tuile sélectionnée · actions). Adapté mobile via un carrousel à la place des trois zones du bas et des bottom-sheets pour les sous-pages.

Décision-clé : les clics sur les tuiles conservent le comportement actuel (observe.php alimente la zone "tuile sélectionnée"). La refonte est visuelle — l'ensemble du gameplay reste intact, pas de réécriture du back-end.

Wireframes

Cliquez sur une vignette pour ouvrir le wireframe !
Vous pourrez y basculer entre les différents états (rien de sélectionné / arbre / autre joueur, panneau fiche / inventaire / journal, etc.) via les boutons en haut de chaque page.

Desktop — Écran principal

Player chip (avatar + race) en haut. A / MVT / PV. Chat panel persistant à droite. Zone basse 3 colonnes. Trois états : neutre, ressource sélectionnée, autre joueur (PvP).

Desktop — Sous-pages en panneau

Trois panneaux illustrés : fiche personnage (avec icônes Faction, École de guerre, Compétences…), inventaire, et journal d'événements. Pattern unique pour toutes les pages.

Mobile — Écran principal (carrousel)

Carrousel 3 panneaux : minimap ↔ sélection ↔ actions. Hamburger top-left ouvre le drawer de navigation, player chip compact, pastille chat overlay sur le map. Pas de tab-bar.

Mobile — Bottom-sheets

Deux exemples : Chat et Fiche personnage. Pills A / MVT / PV restent visibles au-dessus de la sheet. Chrome identique aux panneaux desktop.

Propositions

Sujet Décision Conséquence
Layout HUD Top bar persistante · rail gauche · map central (joueur au centre) · chat persistant à droite · zone basse 3-colonnes Référence visuelle claire, hiérarchie d'information stable
Clic sur tuile Comportement actuel conservé (observe.php) Zéro changement back-end — refonte ≈ 100% CSS/HTML
Sous-pages Panneau glissant intégré (desktop) · bottom-sheet (mobile) · même HTML Refactor de chaque page comme un panneau (gros chantier, page-par-page)
Priorité de design Mobile-first, puis extension desktop Force la priorisation des infos essentielles
Carrousel mobile 3 panneaux swipeables : minimap · sélection+actions · grille d'actions Position par défaut au milieu, dots de pagination
Top bar Player chip + 6 pills (A · MVT · PV · PM · PF · EN) + plan/lieu + Tour suivant + 3 boutons (changer-perso · classements · aide) Identité, caracs visibles en permanence, prochain tour, accès rapides
Tour suivant Horaire informatif (HH:MM), pas de countdown — 18 h pour jouer Aucune urgence visuelle, pas d'animations alarmistes
Player chip → Fiche perso Clic sur le chip = ouvre la fiche en panneau / sheet. Contient les icônes d'accès à Faction, École de guerre, Compétences, etc. Faction / War School deviendront plus tard des bâtiments visitables sur la carte
Chat & événements Anciens "messages du jour" promus en chat persistant — panneau droit desktop · pastille overlay + sheet mobile · onglets Général et Événements Le journal des événements vit dans l'onglet « Événements » (badge non-lus) — pas de sous-page dédiée. Source = players_logs
Navigation Rail vertical gauche desktop · drawer hamburger (depuis la gauche) sur mobile 7 items + Paramètres : Personnage · Carte (monde / locale) · Inventaire / Banque · Craft · Caractéristiques · Sorts / Techniques · Forum · Paramètres (en bas)
Minimap Réutilise l'existant : tactical = local map déjà rendue ; orientation = image du monde (ou absence de map pour les plans comme les Enfers) Pas de nouveau code de rendu nécessaire
Tutorial Pas de wireframe dédié — l'overlay tutoriel s'affiche par-dessus le HUD réel Mettre à jour les target_selector des steps existants

Notes pour les devs

  • Source des données Player chip + caracs = CaracsPanelRenderer. Zone sélectionnée = observe.php. Actions = #ui-card actuel. Tour suivant = players.nextTurnTime. Journal = players_logs. Chat = anciens messages du jour.
  • Net-new components Chat persistant (front + WS/polling), carrousel mobile (JS), panel-router pour les sous-pages glissantes, player card view. (La minimap réutilise les vues map existantes.)
  • Police & icônes Réutilise goudy.ttf et rpg-awesome déjà présents.
  • Cache-busting Penser à incrémenter ?v=YYYYMMDD sur les fichiers JS/CSS modifiés.
